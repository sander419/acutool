# АкуТул

Бизнес-презентация проекта **АкуТул** — акустический мониторинг состояния
режущего инструмента станков ЧПУ.

Одностраничный сайт: чистые HTML + CSS + vanilla JS, без сборки и зависимостей.

## Как показать партнёру

| Что | Где | Когда удобно |
|---|---|---|
| Ссылка | https://sander419.github.io/acutool/ | скинуть в переписке, открыть с любого устройства |
| Один файл | [`dist/АкуТул-презентация.html`](dist/) | ноутбук в цеху, интернета нет; можно отправить файлом |
| Исходник | [`index.html`](index.html) | правки |

Автономный файл из `dist/` (~1,2 МБ) содержит внутри себя шрифты и все
изображения — открывается двойным кликом и работает без интернета.

## Что внутри презентации

- анатомия инцидента «скол зуба фрезы»: сценарии с датчиком и без;
- интерактивный симулятор спектра акустической эмиссии (canvas, режимы
  «норма / тупая фреза / скол зуба», регулируемый порог, журнал событий);
- симуляция установки за 60 секунд;
- макет облачного дашборда парка станков и Telegram-алертов;
- BOM и себестоимость, план 7 / 30 / 90 дней;
- калькулятор окупаемости для клиента;
- разделы для партнёров: юнит-экономика, рынок, конкуренты, FAQ, патентная карта.

## Технология (кратко)

Пьезодатчик → предусилитель → ESP32-S3 (512-точечный FFT, FreeRTOS) →
детектор (порог + автоэнкодер TinyML) → сухой контакт на E-Stop / Feed Hold
и уведомление в Telegram. Рабочая полоса детекции 8–25 кГц.

## Разработка

```
git clone https://github.com/sander419/acutool.git
cd acutool
python -m http.server 4173          # локальный просмотр: http://localhost:4173
python build-offline.py             # пересобрать автономный файл в dist/
```

Правится только `index.html`; `build-offline.py` вшивает в копию шрифты
и картинки. После правок исходника автономный файл нужно пересобрать.

## Структура

```
index.html           презентация
assets/              изображения, иконки, картинка превью для мессенджеров
dist/                автономная версия одним файлом (собирается скриптом)
build-offline.py     сборщик автономной версии
```

## Статус и оговорки

Презентационный материал, не продукт.

- цифры (себестоимость, маржа, план продаж) — плановые оценки, не факт;
- изображения сгенерированы, это не фото готового устройства;
- форма обратной связи ничего никуда не отправляет — показывает заглушку
  «заявка принята». Контакт в блоке «Следующий шаг» нужно заменить на рабочий;
- страница закрыта от поисковой индексации (`robots: noindex`).
